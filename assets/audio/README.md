# Local Audio Assets Directory

Store short audio clips, demo tracks, and MP3 excerpts here (e.g. for the NUS Jazz card or standalone audio demos).

### Best Practices:
- **Format**: MP3 (192kbps - 256kbps stereo recommended for fast web playback).
- **File Size**: Keep individual files ideally under 5 MB to 10 MB for fast mobile loading.
- **Naming**: Use lowercase with hyphens (e.g. `nus-jazz-sample.mp3`, `podcast-demo.mp3`).
